# Developer Portfolio (Demo) 🚀

A modern, interactive, and fully responsive developer portfolio website built with **React 19, TypeScript, Tailwind CSS, and Vite**. This project showcases professional experience, technical skills, featured projects, live code demonstrations, an interactive terminal interface, resume preview, and responsive web/mobile simulation modes.

The application is designed as a high-performance personal portfolio platform that provides recruiters, clients, and developers with an engaging way to explore technical expertise and professional achievements.

---

## ✨ Features

### 🌐 Responsive Portfolio Website

* Fully responsive design for:

  * Desktop
  * Tablet
  * Mobile devices
* Modern UI with smooth transitions and animations
* Dark theme-optimised interface

### 📱 Web & Mobile Simulation Mode

* Switch between:

  * Standard portfolio website view
  * Mobile application simulation view
* Demonstrates responsive design capabilities

### 💻 Interactive Developer Terminal

A built-in CLI-style terminal experience where visitors can explore developer information through commands.

Features:

* Terminal interface

# 🚀 Getting Started

Follow these steps to run the project locally.

## Prerequisites

Make sure you have installed:

* Node.js (v18 or higher)
* npm / yarn/bun

Check versions:

```bash
node -v
npm -v
```

---

## Installation

Clone the repository:

```bash
git clone <your-repository-url>
```

Navigate into the project folder:

```bash
cd Developer-Portfolio
```

Install dependencies:

```bash
npm install
```

or

```bash
bun install
```

---

# ▶️ Running the Development Server

Start the development environment:

```bash
npm run dev
```

The application will run at:

```
http://localhost:3000
```

---

# 🏗️ Production Build

Create an optimized production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

---

# 🧹 Code Quality Check

Run TypeScript validation:

```bash
npm run lint
```

---

# ⚙️ Environment Configuration

Create a `.env` file:

```env
VITE_API_KEY=your_api_key_here
```

For security reasons:

* Never commit `.env`
* Use `.env.example` as a reference
